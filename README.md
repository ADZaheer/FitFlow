## Tech Stack

- **Framework:** React Native (Expo SDK 57)
- **Routing:** Expo Router
- **Styling:** NativeWind (Tailwind CSS)
- **Icons:** Expo Vector Icons (Feather)
- **Language:** TypeScript

## Features

- Modern onboarding & authentication screen
- Clean Tailwind-based UI components
- Fast mobile & web preview with Expo

## Getting Started

### Prerequisites

Make sure you have Node.js and npm (or bun/yarn) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/ADZaheer/FitFlow.git
cd fitflow

# Install dependencies
npm install

# Start the development server
npx expo start
```
